|  | Deskripsi |
| --- | --- |
| **Dataset** | [Mushroom Classification Dataset](https://www.kaggle.com/datasets/uciml/mushroom-classification) — Dataset berisi 8.124 sampel jamur dengan 22 fitur kategorikal yang mendeskripsikan karakteristik fisik jamur, seperti bentuk tutup (*cap-shape*), warna (*cap-color*), bau (*odor*), jenis cincin (*ring-type*), dan lain-lain. Label target adalah `class` dengan dua nilai: `p` (poisonous/beracun) dan `e` (edible/dapat dimakan). |
| **Masalah** | Mengidentifikasi apakah suatu jamur aman dikonsumsi atau beracun hanya berdasarkan karakteristik fisiknya merupakan hal yang sulit dilakukan secara manual, bahkan oleh para ahli sekalipun. Kesalahan identifikasi dapat berakibat fatal bagi manusia. Oleh karena itu, dibutuhkan sistem klasifikasi otomatis yang dapat memprediksi tingkat ketoksikan jamur secara akurat dan andal. |
| **Solusi machine learning** | Membangun pipeline machine learning end-to-end menggunakan **TensorFlow Extended (TFX)** untuk mengotomatisasi seluruh proses mulai dari ingesti data, validasi, transformasi fitur, pelatihan, evaluasi, hingga deployment model. Model yang dibangun merupakan binary classifier berbasis neural network yang memprediksi apakah jamur beracun (`1`) atau tidak (`0`). Target yang ingin dicapai adalah model dengan **AUC ≥ 0.95** dan **BinaryAccuracy ≥ 0.95** agar aman digunakan sebagai alat bantu identifikasi. |
| **Metode pengolahan** | Seluruh 22 fitur bersifat kategorikal (string). Pengolahan dilakukan menggunakan **TensorFlow Transform (TFT)** melalui fungsi `preprocessing_fn` di `mushroom_transform.py`. Setiap fitur kategorikal dikonversi menjadi integer menggunakan `tft.compute_and_apply_vocabulary()`, sehingga menghasilkan fitur baru dengan sufiks `_xf`. Label `class` dikonversi menjadi nilai biner dengan `tf.cast(tf.equal(inputs['class'], 'p'), tf.int64)`, di mana `p` (poisonous) menjadi `1` dan `e` (edible) menjadi `0`. |
| **Arsitektur model** | Model dibangun menggunakan Keras Functional API dengan arsitektur **Multilayer Perceptron (MLP)**: (1) 22 input layer terpisah masing-masing berukuran `(1,)` untuk setiap fitur; (2) layer `Concatenate` untuk menggabungkan semua fitur; (3) Dense layer 64 unit dengan aktivasi ReLU; (4) Dense layer 32 unit dengan aktivasi ReLU; (5) Output layer 1 unit dengan aktivasi Sigmoid untuk klasifikasi biner. Model dikompilasi dengan optimizer `Adam`, loss `binary_crossentropy`, dan metrik `accuracy`. Model dilatih selama **10 epoch** dengan batch size 32, menggunakan 1000 training steps dan 500 eval steps. |
| **Metrik evaluasi** | Model dievaluasi menggunakan **5 metrik** melalui komponen Evaluator TFX dengan konfigurasi TFMA: (1) **ExampleCount** — jumlah sampel yang dievaluasi; (2) **AUC** (Area Under the ROC Curve) — kemampuan model membedakan kelas positif dan negatif; (3) **Precision** — proporsi prediksi beracun yang benar; (4) **Recall** — proporsi jamur beracun yang berhasil terdeteksi; (5) **BinaryAccuracy** — akurasi keseluruhan klasifikasi biner. Recall diprioritaskan agar tidak ada jamur beracun yang lolos teridentifikasi sebagai aman. |
| **Performa model** | Model mencapai performa yang sangat baik pada dataset mushroom, konsisten dengan karakteristik dataset yang memiliki pola fitur yang jelas. Model berhasil memenuhi target yang ditetapkan dengan **BinaryAccuracy > 0.98** dan **AUC > 0.99** pada data evaluasi, menunjukkan model mampu mengklasifikasi jamur beracun dan tidak beracun dengan tingkat kesalahan yang sangat rendah. Nilai Precision dan Recall yang tinggi mengkonfirmasi bahwa model tidak banyak menghasilkan false negative (jamur beracun diprediksi aman), yang merupakan aspek paling kritis dalam use case ini. |
